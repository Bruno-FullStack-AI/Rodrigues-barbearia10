# Rodrigues Barbearia — site em HTML, CSS e JavaScript

Projeto convertido do React/Vite/Tailwind para páginas estáticas.

## Arquivos

- `index.html` — estrutura da página
- `css/styles.css` — visual, layout e animações
- `js/script.js` — menu, galeria, formulário e WhatsApp
- `images/` — logo e fotos dos clientes

## Como abrir

Abra o `index.html` no navegador ou sirva a pasta:

```bash
python3 -m http.server 8080
```
